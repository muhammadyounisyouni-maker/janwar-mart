# Janwar Mart — Laravel version
Animal marketplace for Pakistan (Urdu RTL + English). Converted from the original Python/SQLite project; business rules are unchanged.
See **INSTALL.md** to run it, **TESTING_REPORT.md** for what was tested, `docs/MIGRATION_SPEC.md` for the full migration specification.

## Admin dashboard
`/admin` — sidebar navigation (Overview, Marketplace, People, Vets, Money, Support, System) with live badges, smart overview (KPI cards, 7-day activity chart, ads-by-status and category charts, one-click "ads to review", open requests, doctors to verify, recent activity), quick-find box, light/dark mode, mobile slide-in menu.
